# Last Train London — ARG

A fictional interactive ARG set around a night London Underground journey.

## GitHub Pages

1. Upload the contents of this folder to a public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the Pages deployment to finish.

The entry points are:

- `/` — passenger safety notice
- `/journey/` — interactive journey and refund game

The site is fictional and is not affiliated with TfL.
